# Meat Wash — правила проекта

Статический сайт сети детейлинг-студий Meat Wash (Мясницкая, Технопарк): 3D-сцена Porsche
на Three.js и GSAP ScrollTrigger, каталог цен, локации, клуб, запись во внешний yclients.
Эти правила дополняют глобальную web-команду (`~/.claude/agents/`) и важнее общих, где конкретнее.

## Устройство

- `dist/` — это и есть сайт: `index.html`, `css/`, `js/`, `assets/`. Отдельной папки исходников нет.
- `dist/js/main.js` — загрузка сцены, ScrollTrigger, состояние шапки; `ui.js` — меню, окна записи,
  каталог; `config.js` — тексты услуг и позиции камеры; `configurator.js` — «Примерочная»;
  `scene.js`, `garage.js`, `interior.js`, `water.js` — 3D.
- `dist/assets/meatwash-content.json` — единый источник цен, услуг, адресов и ссылок записи.
- Стили: `style.css` (токены и база) → `cinematic.css` (сцена) → `configurator.css` → `catalog.css`.
  Многие правила `style.css` перекрыты в `cinematic.css` — проверяй, где правило действует на самом деле.

## Ловушки

- Страница грузит `dist/js/scene.bundle.js`, а не `scene.js`. После правки сцены и её модулей —
  `npm run bundle`, бандл в тот же коммит.
- Каталог между `<!-- CATALOG:START -->` и `<!-- CATALOG:END -->` генерирует `scripts/catalog.mjs`
  из JSON. Правь шаблон и данные, затем `npm run catalog`.
- Push в `main` сразу публикует сайт на GitHub Pages (`pages.yml`), его видит клиент.
  В `main` не пушить — только ветка и pull request; сливает владелец.
- Форм сбора данных нет намеренно. Запись — ссылками в yclients, у каждого филиала своя:
  Мясницкая `n975571…/company/906067`, Технопарк `n1982508…/company/1743348`
  (общая `n975571.yclients.com` открывает только Мясницкую).
- Цены и факты — только из JSON. Не выдумывать цифры, отзывы, клиентов, акции, программы лояльности.
- На Windows `core.autocrlf=true`; `.gitattributes` держит текстовые файлы в LF, иначе
  `check:bundle` показывает ложное расхождение.

## Внешний вид

Заказчик сознательно вернул прежний вид: бордово-бежевые токены в начале `style.css`,
горизонтальный логотип в шапке, фото без тонирования. Заголовки — Arsenal SC (шрифт брендбука),
текст — Manrope. Логобук «Стенки Бюро» (`dist/assets/brand/`, фирменный `#861A22`, основной
вертикальный знак, эмблема) — справка, а не требование: к его палитре и знакам сайт не приводить
без отдельного решения заказчика. Sloop Script не подключён (платный).

## Проверки

```
npm run check          # ресурсы, ссылки, якоря, цены, ссылки записи обоих филиалов
npm run check:bundle   # бандл собран из текущего scene.js
npm start              # http://127.0.0.1:4173, открывать через file:// нельзя
```

Вёрстку проверять на 390, 768, 1440 и телефоне в альбомной ориентации: без горизонтальной
прокрутки (мерить `scrollWidth`), без наложений, без ошибок в консоли; отдельно — статичный
режим `?motion=reduce`.
